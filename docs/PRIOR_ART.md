Policy (see `CLAUDE.md` → Working conventions): before building, check this repo, the owner's Mac clone
(usually ahead of `origin/main`), the org's other repos, awesome-lists (https://github.com/topics/awesome-list),
and Context7 / Firecrawl for an OSS tool or official integration. Reuse when a maintained tool fits; build only
when it does not, and say why. Each row below is a decision record; specs carry the per-issue detail.
