# DeviceMotionEvent: requestPermission() static method

Limited availability


This feature is not Baseline because it does not work in some of the most widely-used browsers.

- [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static#browser_compatibility)
- [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)

**Secure context:** This feature is available only in [secure contexts](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Secure_Contexts) (HTTPS), in some or all [supporting browsers](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static#browser_compatibility).

The **`requestPermission()`** static method of the [`DeviceMotionEvent`](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent) interface requests the user's permission to access device motion data from the accelerometer and gyroscope sensors. This method requires [transient activation](https://developer.mozilla.org/en-US/docs/Glossary/Transient_activation), meaning that it must be triggered by a UI event such as a button click.

## [Syntax](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static\#syntax)

jsCopy

```
DeviceMotionEvent.requestPermission()
```

### [Parameters](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static\#parameters)

None.

### [Return value](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static\#return_value)

A [`Promise`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) that resolves with a string which is either `"granted"` or `"denied"`.

### [Exceptions](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static\#exceptions)

The returned promise rejects with the following exceptions:

`NotAllowedError` [`DOMException`](https://developer.mozilla.org/en-US/docs/Web/API/DOMException)

The permission state is `"prompt"` and the calling function does not have [transient activation](https://developer.mozilla.org/en-US/docs/Glossary/Transient_activation).

## [Security](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static\#security)

[Transient user activation](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/User_activation) is required. The user has to interact with the page or a UI element in order for this feature to work.

## [Examples](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static\#examples)

### [Requesting device motion permission on click](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static\#requesting_device_motion_permission_on_click)

jsCopy

```
document.querySelector("button").addEventListener("click", async () => {
  if (typeof DeviceMotionEvent.requestPermission !== "function") {
    // The feature is not available, or does not need permission.
    return;
  }

  const permission = await DeviceMotionEvent.requestPermission();
  if (permission === "granted") {
    window.addEventListener("devicemotion", (event) => {
      console.log(`Acceleration X: ${event.acceleration.x}`);
      console.log(`Acceleration Y: ${event.acceleration.y}`);
      console.log(`Acceleration Z: ${event.acceleration.z}`);
    });
  }
});
```
