## Get started with the Google Home APIs

Welcome to the Home APIs documentation! Here you'll find everything you need to develop and deploy the Google Home APIs.

This page provides an overview of the development cycle for your preferred platform, and quick links to technical documentation to guide you through the process. Let's get started!

For an overview, watch this video to discover some tips and tricks for working with the Home APIs.





## 1\. Pick your platform

[android Android](https://developers.home.google.com/apis/android/get-started) [ios iOS](https://developers.home.google.com/apis/ios/get-started)

## 2\. Prototype with the Sample App

Want to see the Home APIs in action before you start building? Quickly create a prototype using the iOS Sample App to learn key concepts, see code in action, and create the foundation for your integration. [Start with the sample\\
app.](https://developers.home.google.com/apis/ios/sample-app/build)

## 3\. Start building

When you are ready to start building, this roadmap guides you through the steps to integrate the Home APIs into your app. Each stage links to relevant technical documentation, giving you instant access to the info you need, when you need it.



[![](https://developers.home.google.com/static/apis/images/apis-workflow-step-1.svg)](https://developers.home.google.com/apis/ios/sdk)

Step 1

### [Get the SDK](https://developers.home.google.com/apis/ios/sdk)


Testing the SDK and set up your development environment

[![](https://developers.home.google.com/static/apis/images/apis-workflow-step-2.svg)](https://developers.home.google.com/apis/ios/oauth)

Step 2

### [Set up OAuth](https://developers.home.google.com/apis/ios/oauth)


OAuth consent is required to access devices in a user's home

[![](https://developers.home.google.com/static/apis/images/apis-workflow-step-3.svg)](https://developers.home.google.com/apis/ios/initialize)

Step 3

### [Initialize the home](https://developers.home.google.com/apis/ios/initialize)


Create a home object, configure it, and request user permissions

## 4\. Integrate, test & launch

Now that you've completed the essentials, let's get to the fun stuff.



[![](https://developers.home.google.com/static/apis/images/apis-workflow-step-5.svg)](https://developers.home.google.com/apis/ios/overview)

Step 4

### [Implement Home APIs](https://developers.home.google.com/apis/ios/overview)


Choose and implement the APIs using our stepped tech docs

[![](https://developers.home.google.com/static/apis/images/apis-workflow-step-6.svg)](https://developers.home.google.com/apis//ios/test)

Step 5

### [Test your app](https://developers.home.google.com/apis//ios/test)


Get feedback by testing your app with internal users

![](https://developers.home.google.com/static/apis/images/apis-workflow-step-7.svg)

Step 6

### Register your app

access
